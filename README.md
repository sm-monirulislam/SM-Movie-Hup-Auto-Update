# 🎬 Auto Movie Playlist M3U Generator

Password-protected ZIP ব্যবহার করে  
GitHub Actions দিয়ে **auto movie M3U playlist** তৈরি করা হয়।

---

## ✨ Features
- 🔒 ZIP protected source (ZipCrypto)
- ⚙️ Auto run via GitHub Actions
- 📺 JSON + M3U → combined.m3u
- 🧹 কাজ শেষে unlock files delete
- 📁 Output শুধু root এ
